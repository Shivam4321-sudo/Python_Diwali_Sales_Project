# Diwali Sales Analysis

This project is based on **Diwali sales data**.
The main purpose of this project is to explore the data and understand customer buying patterns using Python.

I performed data cleaning, analysis and visualization to find useful information about customers, products, occupations and locations.

##  Project Overview

In this project, I analyzed customer and sales-related data to understand:

* Which age groups are purchasing more
* Which gender has more customers
* Which states have more orders
* Which occupations have more customers
* Which product categories are popular
* How marital status is related to purchasing
* Which products have higher numbers of orders

The analysis was performed using Python and different data visualization techniques.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

##  Dataset

The dataset contains customer and product information from Diwali sales.

It contains **12 columns**:

| Column             | Description                    |
| ------------------ | ------------------------------ |
| `User_ID`          | Unique ID of the customer      |
| `Cust_name`        | Name of the customer           |
| `Product_ID`       | ID of the product              |
| `Gender`           | Gender of the customer         |
| `Age Group`        | Age category of the customer   |
| `Age`              | Age of the customer            |
| `Marital_Status`   | Marital status of the customer |
| `State`            | State of the customer          |
| `Zone`             | Geographical zone              |
| `Occupation`       | Occupation of the customer     |
| `Product_Category` | Category of the product        |
| `Orders`           | Number of orders               |

##  Data Cleaning

Before performing the analysis, I checked the dataset for missing and unnecessary data.

The following steps were performed:

* Checked the shape of the dataset
* Checked column names and data types
* Checked missing values
* Removed unnecessary columns where required
* Checked duplicate records
* Converted data into suitable formats for analysis

##  Exploratory Data Analysis

Different graphs and plots were created to understand the data.

### 1. Gender Analysis

Analyzed the number of customers based on gender and compared their purchasing patterns.

### 2. Age Group Analysis

Analyzed different age groups to understand which age group has more customers and orders.

### 3. State-wise Analysis

Compared customers and orders across different states to identify the states with higher sales activity.

### 4. Marital Status Analysis

Analyzed customer purchasing patterns based on marital status and gender.

### 5. Occupation Analysis

Compared different occupations to understand which occupation groups have more customers and orders.

### 6. Product Category Analysis

Analyzed different product categories to find which categories have higher demand.

### 7. Product Analysis

Analyzed product IDs to identify products with a higher number of orders.

##  Key Findings

Some of the main observations from the analysis include:

* Customer purchasing patterns vary across different age groups.
* Gender has a noticeable difference in the number of customers.
* Some states contribute more orders than others.
* Customer occupation is also related to purchasing patterns.
* Certain product categories have higher demand.
* A small number of products account for a large number of orders.
